# Task 06 — Manual unit tests

Profile: tester (`~/.agents/instructions/tester.md`) and the `~/.agents/coding/` files for the languages involved.

## Goal

Write unit tests that the user will run by hand.

## Steps

1. Read the code to test and the existing tests for conventions, framework and location.
2. Identify the expected behavior, normal cases, edge cases and failure modes.
3. Write reproducible, isolated tests with names that describe the case.
4. Give the exact command to run them, targeted first and then the full suite.

## Output

Test files created, run commands, and cases covered or excluded.

## Limits

Do not run the tests: the user runs them. Do not modify production code.
