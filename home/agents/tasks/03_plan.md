# Task 03 — Code planning

Profile: planner (`~/.agents/instructions/planner.md`).

## Goal

Turn a requirement into a verifiable implementation plan.

## Steps

1. Read the specifications and only the relevant code files.
2. Check that the requirement is compatible with the specifications; if they diverge, report it and ask.
3. Present the plan in chat: files involved, ordered steps, assumptions, risks, dependencies, checks.
4. Ask for confirmation.

## Output

Plan approved by the user; any assumptions recorded in `.agents/project/` as provisional.

## Limits

Do not implement: implementation starts with task 04.
