# Task 05 — Refactoring

Profile: developer (`~/.agents/instructions/developer.md`) and the `~/.agents/coding/` files for the languages involved.

## Goal

Improve readability and maintainability without changing behavior.

## Steps

1. Identify the scope given by the user; if it is missing, ask for it.
2. Read the code and its direct dependencies; briefly describe what you will change and why.
3. Apply small changes consistent with the conventions: names, short functions, removal of dead code and duplication.
4. Flag the points where behavior might change.

## Output

List of changes and regression risks.

## Limits

No new features and no bug fixes (report them). Do not run tests unless explicitly requested.
