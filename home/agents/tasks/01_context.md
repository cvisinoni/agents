# Task 01 — Context and requirements

Profile: planner (`~/.agents/instructions/planner.md`).

## Goal

Gather context and requirements and write them into the specifications.

## Steps

1. Read `.agents/project/` and map the project.
2. Ask for what is missing with targeted questions: goal, scope, requirements, constraints, acceptance criteria.
3. Write goal and scope, requirements and boundaries into `.agents/project/`; record decisions, open questions and assumptions there too. Follow the existing file structure; if there is none, choose a simple one.

## Output

Updated specifications and a short summary of the requirements and the questions still open.

## Limits

Do not design the architecture and do not touch the code.
